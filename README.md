# Cozy Haven 🌾

A peaceful farming adventure game built with React Native and Expo.

## Quick Start

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm start
   ```

3. Open the app:
   - **Web**: Press `w` in the terminal or visit http://localhost:8083
   - **Mobile**: Scan the QR code with Expo Go app

## How to Play

- **New Game**: Start your farming adventure
- **Plant Crops**: Select seeds and plant them in farm plots
- **Water Crops**: Keep crops healthy and growing
- **Harvest**: Collect mature crops for coins
- **Build**: Place buildings on your farm
- **Mine**: Extract valuable ores from deposits

## Game Controls

- Use the action buttons to select activities
- Click on farm plots to interact with them
- Manage your inventory and resources
- Save your progress anytime

## Technologies

- React Native with Expo
- TypeScript
- Zustand for state management
- Canvas for game rendering

Enjoy your cozy farming experience! 🏡
